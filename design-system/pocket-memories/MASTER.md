# Pocket Memories design system

The UI UX Pro Max searches informed the editorial grid, paper treatment, mobile storytelling, Vietnamese font pairing, and reduced-motion behavior. The project brief sets the final colors and fonts.

| Token | Value | Role |
| --- | --- | --- |
| Ivory | #F8F6F1 | Page and letter |
| Sage | #899789 | Envelope and paper accents |
| Dusty rose | #D8B9B0 | Wax and scrapbook accents |
| Warm paper | #EAE0D3 | Stationery panels |
| Dark ink | #30352F | Headlines and readable foreground |
| Deep sage | #455344 | Primary actions |
| Soft ink | #596157 | Supporting text |
| Display | Cormorant Garamond | English editorial headings |
| Body | Be Vietnam Pro | Vietnamese copy and UI |
| Gutter | 20–24px | Mobile safe spacing |
| Touch | 48px | Minimum control height |

Use a single vertical story with chapter landmarks. Maintain 16px body copy and visible focus. Desktop uses wider framed compositions, with a single-column album on mobile. Paper edges, inset rules, and shadows imply depth. Envelope motion uses a short seal release, a perspective flap, and a rising letter. Scroll effects run once, with a static readable presentation for reduced motion. CSS tokens live in `src/index.css`.
